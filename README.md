# alu-web_react

Front-end web development curriculum projects.

| Project | Description |
| --- | --- |
| [TypeScript](./TypeScript) | Basic types, interfaces, classes, generics, namespaces, declaration merging, ambient namespaces and nominal typing. |
| [Webpack](./Webpack) | Entry points, output, loaders, plugins, code splitting and the dev server. |
| [react_intro](./react_intro) | React with JSX, `create-react-app`, Enzyme shallow-rendering tests, a GitHub Pages deploy, and the same app rebuilt on Webpack + Babel. |
| [react_props](./react_props) | Function components, props, PropTypes and shapes, Fragments, and keyed list rendering. |
| [React_component](./React_component) | Class components and lifecycle, event handling, Jest spies, higher-order components, and render control. |

## Deployed app

The React dashboard is live at <https://helloworldvictor.github.io/alu-web_react>.
